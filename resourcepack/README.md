# Resource pack

`StrataSMP-Resources.zip` is the previous Milly pack rebranded: `millysmp` / `millybosses` paths and references renamed to `stratasmp` / `stratabosses`, pack description set to "StrataSMP". Keep `pack.mcmeta` and `assets/` at the zip root.

Set in `server.properties`:
- `resource-pack=<public https url of the zip>`
- `resource-pack-sha1=0b44cfbb40f5a75fdc188a7b64001313c0a193e8` (changes whenever the zip is rebuilt)

`artwork/` holds the StrataCharm store artwork (still the old Skin Charm image; redraw before launch).
Some inherited weapon models may lack redistribution credits; review rights before publishing the pack publicly.
